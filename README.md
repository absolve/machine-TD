# Machine-TD · 简易塔防

一个用 **Godot 4.7** 制作的 2D 塔防游戏。

流水线是敌人的行进路线，你在路边的空位上建塔，把它们拦在出口之前。
**9 座塔、12 种敌人、16 个关卡 + 无尽模式**，外加 4 种可以自由切换的战斗模式。

---

## 项目背景

我自己喜欢玩塔防，但很多塔防要么上手门槛高，要么后期变成纯数值堆叠 ——
所以想做一版**规则看得懂、但每关都能学到点新东西**的。

设计上的几个取舍：

- **不做"造兵 + 微操"**：玩家只做三件事 —— 建塔、看敌人、按技能。决策集中在"摆哪里"和"什么时候开"。
- **塔靠击杀升级**（不是花钱升级）：逼你把塔分散沿路摆，而不是把所有资源堆在一处。
- **每一关只引入一个新威胁**：从"只会往前冲的迷你坦克"开始，逐步加对抗型、空中、维修、自爆。
- **美术全部自己画**：统一在"明亮装配车间"一个场景语言里（俯视平涂、深蓝灰地砖 + 安全黄点缀）。

技术上是一个单机项目：Godot 4.7（GL Compatibility）、纯 GDScript、无联网、无第三方 SDK。
**完全免费，没有广告和内购**，存档就放在本地。

## 玩法

### 核心循环

选关 → 打波次 → 结算（星级 / 宝石 / 分数）→ 解锁下一关。守住就过关，漏怪扣基地血量。

### 防御塔

| 塔 | 定位 |
|---|---|
| 机枪塔 | 射速快、射程短，前期主力 |
| 加农炮 | 单发高伤、打得慢 |
| 火箭塔 | 追踪弹 + 范围伤害，怕成群的散兵；能打空 |
| 激光塔 | 同时锁定最多 3 个目标，持续灼烧；能打空 |
| 特斯拉线圈 | 电弧在敌人之间连锁跳跃 |
| EMP 干扰塔 | 不造成伤害，只减速（敌人只会受最强的一座影响） |
| 无人机基地 | 放出一队无人机出去咬人；能打空 |
| 铁箱塔 | 不能攻击，但能挡住敌人 —— 当肉盾 / 路障用 |
| **移动机甲** | 不攻击的后勤单位：跑到受损的塔旁边用激光修塔，也能回收战场残骸换钱 |

**塔靠击杀涨经验，满了自动升 Lv.2 / Lv.3**（伤害、射速、射程都提升）。
所以别把塔挤在一起 —— 沿路分散摆才能持续拿到人头。
（EMP 干扰塔与铁箱塔按设计不参与升级。）

### 每个塔都有一个主动技能

技能分三种形态，**都有代价**，不是白给的按钮：

- **限时增益**：机枪塔「过热扫射」3 秒内攻击 ×2、射速 ×2，但每秒自损 6 点血。
- **功能切换**：火箭塔切成「远距离导弹」—— 射程 ×1.6、伤害更高，但**失去爆炸范围**；
  激光塔切成「单体打击」—— 只锁 1 个目标、对单伤害 ×2.2，但打群明显变弱。
- **瞬发**：机甲的「紧急维修」立刻给自身和范围内所有塔回 30% 血，**之后整机停止 3 秒**（不能动、不能修、不能捡残骸）。

### 敌人不只是"往前走然后被打死"

- **推进型**：只顾冲基地，不理你的塔
- **对抗型**：会停下来打你的塔
- **支援型**（维修车）：给敌人回血，不先处理掉，前面输出全白费
- **自爆型**：冲进塔堆就炸
- **空中单位**：只有少数塔打得到
- **要塞型**（实验坦克）：4 座炮塔、血极厚

点一下敌人，脚下会画出它的攻击范围（和防御塔同一套画法的雷达圈），不用靠猜。

### 星级与宝石

- 星级按**基地剩余血量**算：≥90% 是 3★，≥50% 是 2★，其余 1★
- **首次通关**给该关的宝石；**刷新最高星级**额外给宝石（★★ +25%，★★★ +50%）
- 宝石是战略资源：可以呼叫**区域轰炸**（范围伤害）或**防御塔无敌**（短暂免疫）

### 四种战斗模式

同一张图换一套规则重打，在关卡选择页切换：

| 模式 | 规则 |
|---|---|
| **正常** | 标准数值，只有这个模式会记录星级和成就 |
| **蜂群** | 敌人数 ×2、血量 −50%、出怪更快 —— 考验范围伤害 |
| **铁流** | 数量不变、血量 ×2 —— 考验破甲与持续输出 |
| **精锐** | 血量 ×1.3、攻击 ×1.5 —— 考验塔的血量管理 |

挑战模式**不记录星级和成就**，但首次通关的宝石更多。进关前和战斗中都会显示当前模式。

### 无尽模式

没有终点，看你能撑到第几波。基地只有 10 点血，后期同屏最多 90 个敌人，敌人每波变强，每 10 波额外奖励宝石。

### 其他

- **单位图鉴**：所有敌人和塔的血量、护甲、射速、射程都能查
- **12 个成就**
- **1X / 2X 倍速**
- 中文 / English 双语

## 运行

1. 用 Godot 4.7 打开 `machine-td/` 目录（**不是**仓库根目录）
2. 直接 F5 运行，主场景是 `scene/welcome.tscn`
3. 首次打开编辑器时会自动从 `lang/language.csv` 重新生成翻译文件

> 需要现成的可执行版本时，用 Godot 的导出功能打 Windows 包（`build/windows/` 下已有导出产物）。
